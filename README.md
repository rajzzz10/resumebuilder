# 📝 Resume Builder Website

Welcome to the **Resume Builder** – a powerful, responsive web app where users can create professional resumes by choosing from multiple templates, entering their details, and downloading them as **A4-size PDFs**.

---

## 🚀 Features

- 🎨 **Multiple Resume Templates** – Pick from a variety of clean and modern designs  
- ✍️ **Customizable Sections** – Add Personal Info, Education, Skills, Experience, Certifications, and more  
- 🧠 **Category Based Forms** – Different form flows for Freshers, Midlevel, and Expert users  
- 🔄 **Live Preview** – See your resume update in real-time as you fill out the form  
- 📄 **PDF Export** – Download your resume in perfect **A4 size**, ready to print or send  
- 📃 **Multi-Page Support** – Automatically adds new pages for long resumes  
- 📱 **Responsive Design** – Works beautifully across devices  

---

## 💡 How It Works

1. **Select a Category** – Fresher / Midlevel / Expert  
2. **Choose a Template** – Each category comes with multiple template styles  
3. **Fill the Form** – Input your resume data in a user-friendly interface  
4. **Live Preview** – Instantly see your resume on the right side of the screen  
5. **Download PDF** – Export the resume in A4 size with all sections included

---

## 🛠️ Tech Stack

- **React.js** – Frontend UI  
- **Tailwind CSS** – Styling  
- **react-to-print** or **jsPDF** – For generating downloadable PDF  
- **React Router** – Routing and navigation  
- **Context API / Zustand / Redux** – State Management (choose what you used)
